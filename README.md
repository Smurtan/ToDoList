# ToDoList
"You don't have to be great to start, but to become great you have to start." Zig Ziglar
And you need to start with the simple, going to the complex.

This repository is a ToDo console application in python.
The following functions are present:
- View the entire to-do list
- Adding a task
- Deleting an issue
- Saving and outputting the task list from a text file.
